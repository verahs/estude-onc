# Fluxo Git recomendado

## Versão pública
A branch `main` contém apenas versões testadas e publicáveis.

## Desenvolvimento
Para próximas sprints:

1. No GitHub Desktop, acesse `Branch > New branch`.
2. Use um nome como `develop-sprint-3`.
3. Faça as alterações e testes nessa branch.
4. Publique na `main` somente após validação.

## Commit
Use mensagens objetivas:

- `Sprint 2 - Arquitetura do conteúdo`
- `Correção - Carregamento de tópicos`
- `Conteúdo - Revisão de Astronomia`

Não inclua arquivos ZIP de backup dentro do repositório.
