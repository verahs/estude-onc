# Esquema de Conteúdo Flexível

## Núcleo mínimo
- título;
- disciplina;
- definição ou explicação central;
- aplicação contextualizada;
- exemplo de cobrança.

## Blocos opcionais
- pergunta de abertura;
- analogia;
- comparação;
- evidências;
- sequência/fluxo;
- experimento;
- tabela;
- gráfico;
- diagrama;
- exemplo resolvido;
- erro comum;
- revisão rápida;
- vídeo complementar.

Nenhum bloco opcional deve ser incluído apenas para preencher espaço.
