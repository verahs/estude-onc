# Sprint 7.3.3.1 — Motor de Regras de Medalhas

## Estrutura de cada regra
- id;
- título;
- categoria;
- descrição;
- visibilidade;
- recompensa;
- função de avaliação;
- progresso;
- meta;
- percentual;
- evidência;
- estado de desbloqueio.

## Garantias
- regras modulares;
- sem medalhas duplicadas;
- dados separados por estudante;
- histórico de avaliações;
- regras secretas ocultas até o desbloqueio;
- critérios explicáveis.

## Regras iniciais
- Primeiro Passo;
- Consistência Inicial;
- Revisor;
- Recuperação Inicial;
- Ascensão Aprendiz;
- Curiosidade Científica (secreta).
