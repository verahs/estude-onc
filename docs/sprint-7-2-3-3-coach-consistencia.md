# Sprint 7.2.3.3 — Coach de Consistência

## Indicadores
- dias ativos;
- regularidade entre sessões;
- sequência;
- equilíbrio entre disciplinas;
- concentração da carga.

## Saídas
- índice de consistência;
- meta semanal;
- sinais;
- plano de redistribuição;
- recomendação de disciplina;
- relatório detalhado.

## Limites
O Coach descreve padrões de uso. Não avalia disciplina pessoal, motivação, personalidade ou saúde mental.
