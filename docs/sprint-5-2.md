# Sprint 5.2 — Dashboard Avançado

## Entregas

### Radar de aprendizagem
Mostra o domínio médio por disciplina.

### Atividade semanal
Resume:
- minutos estudados;
- tópicos visitados;
- questões;
- dias ativos.

### Insights
Destaca:
- maior domínio;
- maior oportunidade;
- maior cobertura.

### Painel do responsável
Apresenta:
- atividade semanal;
- precisão;
- domínio médio;
- principal ponto de atenção;
- próximo passo recomendado.

### Relatório imprimível
O painel do responsável pode ser impresso diretamente pelo navegador.

## Limites
Os dados são locais e dependem do histórico armazenado no navegador.
