# Sprint 3 — Experiência de estudo

## Objetivo
Transformar o módulo Estudar em uma ferramenta de uso diário.

## Entregas
- favoritos;
- retomada do último tópico;
- progresso por disciplina;
- tempo estimado de leitura;
- estatísticas semanais;
- registro de sessões;
- revisão espaçada;
- atalhos de teclado.

## Observação
Os dados continuam armazenados localmente no navegador. Sincronização entre aparelhos exigirá backend em sprint futura.
