# Biblioteca Visual Premium

## Escopo
Foram criadas 141 ilustrações SVG, uma para cada tópico.

## Características
- formato vetorial;
- resolução independente;
- identidade visual por disciplina;
- gradientes e sombras;
- leitura didática;
- zoom em tela cheia;
- carregamento lazy;
- uso em tópicos e questões.

## Estrutura
```text
assets/illustrations/<topic-id>.svg
data/visual-library.json
js/visual-library.js
css/visual-library.css
```

## Direção visual
A biblioteca adota um estilo semirrealista editorial. O objetivo é combinar clareza pedagógica, consistência e leveza; não simular fotografia.
