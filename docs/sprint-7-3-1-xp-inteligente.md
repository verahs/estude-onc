# Sprint 7.3.1 — XP Inteligente

## O que gera XP
- resposta correta com dificuldade ponderada;
- recuperação após erros;
- revisão;
- conclusão de missão;
- marco de domínio;
- consistência.

## O que não ocorre
- erro não retira XP;
- adiamento não gera saldo negativo;
- XP já conquistado não é confiscado.

## Antifraude
- resposta muito rápida;
- repetição recente da mesma questão;
- limite pedagógico diário.

Esses fatores reduzem ou anulam somente a recompensa daquele evento.

## Níveis iniciais
Explorador → Aprendiz → Pesquisador → Naturalista → Cientista → Especialista → Mestre ONC → Lenda ONC.
