# Manual de Identidade Pedagógica

Este documento é a constituição pedagógica do Estude ONC.

## Princípios inegociáveis

### Clareza antes de formalismo
O conceito formal só deve aparecer depois que o estudante tiver uma base concreta para compreendê-lo.

### Precisão sem excesso
Simplificar a linguagem não autoriza simplificar o conceito de modo incorreto.

### Recurso visual com função
Uma imagem deve ensinar, comparar, localizar, demonstrar ou organizar. Imagens meramente decorativas não entram no conteúdo.

### Estrutura flexível
Cada tema recebe apenas os blocos necessários. Comparação, experimento, gráfico, linha do tempo e cálculo aparecem somente quando favorecem a aprendizagem.

### Evidência e raciocínio
As atividades devem pedir ao estudante que observe dados, identifique evidências, compare possibilidades e justifique conclusões.

### Coerência com a ONC
Questões devem privilegiar contexto, interdisciplinaridade e interpretação, evitando depender apenas de memorização.

## Regra de publicação

Um tópico retorna para revisão quando:
- a definição repete o título;
- o exemplo não explica o conceito;
- há termo técnico não explicado;
- o recurso visual não acrescenta informação;
- a questão possui mais de uma alternativa defensável;
- a leitura exige pesquisa externa para compreender o essencial.
