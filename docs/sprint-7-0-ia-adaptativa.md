# Sprint 7.0 — IA Adaptativa e Motor Pedagógico

## Fluxo

```text
Resposta
  → Learning Engine
  → Perfil cognitivo
  → Mastery + Memory
  → Knowledge Graph
  → Recommendation Engine
  → Adaptive Planner
  → Dashboard e missão
```

## Perfil por tópico
- precisão;
- precisão recente;
- velocidade média;
- consistência;
- confiança estatística;
- tendência;
- erros dominantes;
- sequência de acertos;
- esquecimentos após revisão.

## Recomendação
A pontuação considera:
- recorrência histórica;
- erro recente;
- esquecimento;
- baixo domínio;
- inatividade;
- dificuldade de resposta;
- confiança;
- risco para tópicos dependentes.

## Explicabilidade
Toda recomendação apresenta razões legíveis e mantém uma auditoria técnica local.

## Limites
O motor funciona no navegador e não utiliza modelo generativo. Seus indicadores são auxiliares e não equivalem a diagnóstico ou previsão oficial de desempenho.
