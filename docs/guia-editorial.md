# Guia Editorial — Estude ONC

## Premissas obrigatórias

1. Nenhum tópico será publicado enquanto não for possível responder:
   **“Existe uma maneira mais clara de explicar isso para um aluno de 11 anos?”**

2. Antes de escrever qualquer definição:
   **“Como eu explicaria isso para a Helena usando apenas uma folha de papel, um lápis e cinco minutos de conversa?”**

## Ordem recomendada de construção

A ordem não é um template rígido. Sempre que pertinente:

1. partir de uma pergunta, observação ou situação concreta;
2. construir uma explicação intuitiva;
3. apresentar a formulação científica;
4. escolher apenas os recursos didáticos necessários;
5. aplicar o conceito em uma situação semelhante à ONC.

## Linguagem

- Frases curtas e completas.
- Termos técnicos somente quando necessários e sempre explicados.
- Não infantilizar o estudante.
- Evitar metáforas que produzam erro conceitual.
- Não usar frases genéricas aplicáveis a qualquer assunto.

## Autossuficiência

O tópico deve conter o necessário para que o estudante compreenda o conceito fundamental sem pesquisa externa obrigatória.
